# Variables Challenges 🧩

Try to solve these challenges **without looking at the solution**.

---

## 🟢 Challenge 1 — Personal Information

Create variables for:

* Your name
* Your age
* Your department
* Your university
* Your CGPA

Then print all of them.

### Expected Output

```text
Name: Farzana
Age: 20
Department: CSE
University: Southeast University
CGPA: 3.75
```

---

## 🟢 Challenge 2 — Change a Value

Create a `let` variable:

```javascript
let score = 50;
```

Change the score to `90` and print it.

### Expected Output

```text
90
```

---

## 🟢 Challenge 3 — Constant

Create a `const` variable containing your birth year.

Try to change its value.

Observe what happens.

---

## 🟡 Challenge 4 — Student Information

Create:

```javascript
const studentName = "Your Name";
const university = "Your University";

let semester = 9;
let cgpa = 3.75;
```

Then change the semester and CGPA.

Print all information.

---

## 🟡 Challenge 5 — Swap Two Variables

Given:

```javascript
let a = 10;
let b = 20;
```

Swap their values.

### Expected Output

```text
a = 20
b = 10
```

---

## 🔴 Challenge 6 — Variable Experiment

Create three variables:

```javascript
let x = 10;
let y = 20;
const z = 30;
```

Try:

1. Changing `x`
2. Changing `y`
3. Changing `z`

Write down which operations work and which produce an error.

---

## ⭐ Bonus Challenge

Create variables representing:

```text
Name
Age
Height
Is Student
Favorite Language
```

Choose appropriate variable declaration keywords (`let` or `const`) for each one and explain why.

---

### 🎯 Goal

After completing these challenges, you should understand:

* Variable declaration
* `let`
* `const`
* Reassignment
* Basic variable naming
