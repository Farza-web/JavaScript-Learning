# Data Types Challenges 🧩

Try to identify and work with different JavaScript data types.

---

## 🟢 Challenge 1 — Identify Data Types

Create variables containing:

```javascript
"JavaScript"
25
3.75
true
null
undefined
```

Use `typeof` to identify their types.

---

## 🟢 Challenge 2 — Student Data

Create:

```javascript
let name = "Farzana";
let age = 20;
let cgpa = 3.75;
let isStudent = true;
```

Print each value and its data type.

### Expected

```text
Farzana → string
20 → number
3.75 → number
true → boolean
```

---

## 🟢 Challenge 3 — Array

Create an array containing five programming languages.

Print:

1. The complete array
2. The first element
3. The last element
4. The array length

---

## 🟡 Challenge 4 — Object

Create a student object containing:

```text
name
age
department
university
cgpa
```

Example:

```javascript
let student = {
    name: "Farzana",
    age: 20,
    department: "CSE",
    university: "Southeast University",
    cgpa: 3.75
};
```

Print each property.

---

## 🟡 Challenge 5 — Data Type Detector

Create different variables and use `typeof` to determine their types.

Try:

```javascript
let a = "Hello";
let b = 100;
let c = false;
let d;
let e = null;
```

Record the output.

---

## 🟡 Challenge 6 — BigInt

Create a very large integer using `BigInt`.

Example:

```javascript
let bigNumber = 12345678901234567890n;
```

Print the value and its type.

---

## 🔴 Challenge 7 — Predict Before Running

Without running the code, predict the output:

```javascript
console.log(typeof "Hello");
console.log(typeof 100);
console.log(typeof true);
console.log(typeof undefined);
console.log(typeof null);
```

Then run the code and compare your answers.
