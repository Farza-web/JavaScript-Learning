# Operators Challenges 🧩

Practice arithmetic, comparison, logical, and assignment operators.

---

## 🟢 Challenge 1 — Basic Calculator

Create:

```javascript
let a = 20;
let b = 5;
```

Calculate:

* Addition
* Subtraction
* Multiplication
* Division
* Remainder

---

## 🟢 Challenge 2 — Student Marks

Create:

```javascript
let math = 80;
let english = 75;
let science = 90;
```

Calculate:

* Total marks
* Average marks

### Expected

```text
Total: 245
Average: 81.666...
```

---

## 🟢 Challenge 3 — Comparison

Given:

```javascript
let a = 15;
let b = 10;
```

Check:

```text
a > b
a < b
a === b
a !== b
a >= b
a <= b
```

---

## 🟡 Challenge 4 — `==` vs `===`

Predict the result before running:

```javascript
console.log(5 == "5");
console.log(5 === "5");
console.log(10 != "10");
console.log(10 !== "10");
```

Explain why the results are different.

---

## 🟡 Challenge 5 — Logical Operators

Given:

```javascript
let age = 22;
let hasID = true;
```

Check whether:

* Age is at least 18 **AND** the person has an ID.
* Age is below 18 **OR** above 60.
* The person does **not** have an ID.

---

## 🟡 Challenge 6 — Increment & Decrement

Create:

```javascript
let count = 10;
```

Then:

1. Increase it by 1.
2. Increase it by 5.
3. Decrease it by 2.
4. Print the final value.

---

## 🔴 Challenge 7 — Bill Calculator

A product costs:

```javascript
let price = 500;
let quantity = 3;
```

Calculate the total bill.

Then add a 10% discount.

Print:

```text
Original Price:
Discount:
Final Price:
```

---

## 🔴 Challenge 8 — Even or Odd

Given:

```javascript
let number = 17;
```

Use the `%` operator to determine whether the number is even or odd.

---

## ⭐ Bonus Challenge — Ternary

Given:

```javascript
let age = 20;
```

Use the ternary operator to print:

```text
Eligible
```

if age is 18 or above, otherwise:

```text
Not Eligible
```

After completing these challenges, you should understand:
