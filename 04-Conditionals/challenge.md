# Conditional Statement Challenges 🧩

Practice making decisions using `if`, `else if`, `else`, and `switch`.

---

## 🟢 Challenge 1 — Positive or Negative

Create:

```javascript
let number = 10;
```

Check whether the number is:

* Positive
* Negative
* Zero

---

## 🟢 Challenge 2 — Even or Odd

Create:

```javascript
let number = 25;
```

Check whether it is even or odd.

---

## 🟢 Challenge 3 — Voting Eligibility

Create:

```javascript
let age = 20;
```

If age is 18 or above:

```text
Eligible to vote
```

Otherwise:

```text
Not eligible to vote
```

---

## 🟡 Challenge 4 — Grade Calculator

Create:

```javascript
let marks = 85;
```

Use conditions:

```text
80–100 → A+
70–79  → A
60–69  → A-
50–59  → B
40–49  → C
Below 40 → F
```

Print the appropriate grade.

---

## 🟡 Challenge 5 — Largest Number

Given:

```javascript
let a = 25;
let b = 40;
let c = 30;
```

Find the largest number using conditional statements.

### Expected Output

```text
Largest: 40
```

---

## 🟡 Challenge 6 — Login Check

Create:

```javascript
let username = "admin";
let password = "1234";
```

Check:

```text
Correct username + correct password
→ Login successful

Otherwise
→ Invalid username or password
```

---

## 🔴 Challenge 7 — Simple Calculator

Create:

```javascript
let a = 20;
let b = 10;
let operator = "+";
```

Use `if...else` or `switch` to perform:

```text
+
-
*
/
```

Example:

```text
Result: 30
```

---

## 🔴 Challenge 8 — Day of the Week

Create:

```javascript
let day = 3;
```

Use `switch`:

```text
1 → Monday
2 → Tuesday
3 → Wednesday
4 → Thursday
5 → Friday
6 → Saturday
7 → Sunday
```

---

## ⭐ Bonus Challenge

Create a program that checks whether a person can enter a club.

Conditions:

```text
Age must be 18+
AND
Must have an ID
```

Print either:

```text
Entry Allowed
```

or:

```text
Entry Denied
```

### 🎯 Goal

After completing these challenges, you should understand:

* `if`
* `else`
* `else if`
* Nested conditions
* `switch`
* Logical conditions
* Decision making
