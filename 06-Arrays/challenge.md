# Arrays Challenges 🧩

Practice creating, accessing, modifying, and looping through arrays.

---

## 🟢 Challenge 1 — Create an Array

Create an array containing five programming languages.

Example:

```javascript
let languages = [
    "JavaScript",
    "Python",
    "C",
    "C++",
    "Java"
];
```

Print the array.

---

## 🟢 Challenge 2 — Access Elements

Using your array, print:

* First element
* Second element
* Last element

Remember that array indexing starts from `0`.

---

## 🟢 Challenge 3 — Change an Element

Given:

```javascript
let fruits = ["Apple", "Mango", "Banana"];
```

Change `"Mango"` to `"Orange"`.

Expected:

```text
["Apple", "Orange", "Banana"]
```

---

## 🟢 Challenge 4 — Add Elements

Given:

```javascript
let fruits = ["Apple", "Mango"];
```

Use `push()` to add:

```text
Banana
Grapes
Orange
```

---

## 🟡 Challenge 5 — Remove Elements

Given:

```javascript
let fruits = [
    "Apple",
    "Mango",
    "Banana",
    "Orange"
];
```

Use:

* `pop()` to remove the last element.
* `shift()` to remove the first element.

Print the final array.

---

## 🟡 Challenge 6 — Search an Array

Create an array of programming languages.

Use:

```javascript
includes()
```

to check whether:

```text
JavaScript
Python
Java
```

exist in the array.

---

## 🟡 Challenge 7 — Find an Index

Given:

```javascript
let languages = [
    "Python",
    "JavaScript",
    "C++",
    "Java"
];
```

Use `indexOf()` to find the position of:

```text
JavaScript
C++
```

---

## 🟡 Challenge 8 — Loop Through an Array

Create an array of five names.

Print every name using:

```javascript
for
```

Then do the same using:

```javascript
for...of
```

---

## 🔴 Challenge 9 — Find the Largest Number

Given:

```javascript
let numbers = [10, 25, 7, 45, 30];
```

Use a loop to find the largest number.

### Expected Output

```text
Largest: 45
```

---

## 🔴 Challenge 10 — Calculate Array Sum

Given:

```javascript
let numbers = [10, 20, 30, 40, 50];
```

Calculate the sum using a loop.

### Expected Output

```text
Sum: 150
```

---

## 🔴 Challenge 11 — Count Even Numbers

Given:

```javascript
let numbers = [10, 15, 22, 33, 40, 51, 60];
```

Count how many numbers are even.

### Expected Output

```text
Even numbers: 4
```

## ⭐ Advanced Beginner Challenge

Create an array:

```javascript
let numbers = [5, 10, 15, 20, 25];
```

Create a new array containing the numbers multiplied by `2`.

Expected:

```text
[10, 20, 30, 40, 50]
```

Try to solve it using a loop first.

---

### 🎯 Goal

After completing these challenges, you should understand:

* Creating arrays
* Array indexes
* Accessing elements
* Modifying elements
* `push()`
* `pop()`
* `shift()`
* `unshift()`
* `indexOf()`
* `includes()`
* Array loops
